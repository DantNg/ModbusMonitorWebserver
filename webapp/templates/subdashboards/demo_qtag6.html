So sánh Qtag4 vs Qtag6

Thuộc tính Qtag 4 Tag (hiện tại) Qtag 6 Tag (mới)
Số Tag 4 tags (PV left, PV right, SV left, SV right) 6 tags (+ tag5 LOW/HIGH left, tag6 LOW/HIGH right)
LOW/HIGH Không có Mỗi SV có LOW + HIGH (chọn Tag hoặc Fixed value)
DB Schema tag1_id → tag4_id tag1_id → tag6_id + low/high config columns
Layout 2 sub-cards (PV + SV mỗi bên) 2 sub-cards (PV + SV block có LOW/HIGH mỗi bên)
card_type quad4 (default) quad6
Alarm So sánh PV vs SV So sánh PV vs SV + check LOW/HIGH thresholds
Backward Compatible — ✅ Qtag4 cũ vẫn hoạt động bình thường, tag5/tag6 nullable
